# Playwright Design QA Skill

## Purpose
This skill enables an agent to act as a **Design QA Engineer**.

Its responsibility is to verify that a UI implementation (generated by Claude
using React and Tailwind) matches the Figma prototype provided by Figma MCP.

This skill focuses exclusively on **design fidelity**, not business logic or APIs.

---

## Assumptions
- The frontend application is already running locally.
- The UI was implemented using React + Tailwind CSS.
- Figma MCP has already exported:
  - A prototype screenshot (PNG)
  - A design specification (JSON)
- Key UI elements include stable selectors (`data-testid`, roles, or ids).

---

## Inputs

### 1. Figma Prototype Screenshot
- Path: `design-references/<page-name>.png`
- Acts as the **visual source of truth**

### 2. Design Specification
- Path: `design-specs/<page-name>.json`
- Contains expected design tokens and layout rules

Example:
```json
{
  "page": "Login",
  "elements": {
    "primaryButton": {
      "text": "Sign In",
      "height": 44,
      "borderRadius": 8,
      "backgroundColor": "#1E40AF"
    }
  }
}
